## rekordbox の選択に追従する（`rekordbox/selection.py`）

- 測定: rekordbox は起動中、ツリーの選択をどこにも書かない（browseSetting.xml は保存/終了時のみ、DB は不変）。
- rekordbox（JUCE）は OS のアクセシビリティに UI を公開している。ブラウザ下のステータス行
  「96 トラック, 10 時間 55 分, 1.5 GB」を読み、曲数・合計分・容量（MiB）の指紋を全プレイリストと照合する。
  1 回 15ms、1.2 秒ごと。
- 同じ指紋が複数（Set Agent フォルダに書き出した同じ中身など）なら、今表示中のもの → Set Agent フォルダ外の順に選ぶ。
  コレクション全体・検索結果・デバイスなど一致しないときは表示を変えない。
- macOS はアクセシビリティ許可が必要（設定に「許可する」）。Windows は UI Automation（comtypes）で同じ行を読む実装だが **実機未検証**。

## 改善版（`agent/improve.py`）

| 介入度 | すること |
|---|---|
| 控えめ (light) | 曲は変えない。相性の悪い並び（隣り合う曲が Camelot 3 歩以上 / BPM 8% 超）の後ろの曲を、4 曲以内の曲と入れ替え。入れ替えは 10 曲に 1 回まで |
| 標準 (standard) | 控えめ＋目標尺に合わせる: 超過は外しても響かない曲から外す（removal）、不足はライブラリから BPM/キーで繋がる曲を足す（fillplan、履歴の共起を加点） |
| 大胆 (bold) | 固定以外を、隣り合う曲の相性のコストと目標カーブで貪欲に並べ直し＋局所の入れ替え＋尺合わせ |

- 固定（位置のロック）とマイルストーンの曲は全レベルで動かさない。これらは playlist ID ごとに `intent.json` に保存。
- 決定的（LLM 不要）。acid（96 曲）で 0.4 秒以内。「動かす」は最長増加部分列の外の曲だけ数える（1 回の入れ替え = 1）。
- 書き出し名は「元の名前 (介入度)」。

## チャット層のツール（計 24）

`set.propose_improvement`（改善版を作って見せる）、`lib.taste_profile`（演奏履歴のアーティスト・ジャンル・BPM 帯・キー、
よくかける曲、月別のインポート、高評価ジャンル）、`rekordbox.playlist_profiles`（全プレイリストの要約でコンセプト選び）、
`rekordbox.propose_metadata`（コメント・レーティング・カラーの書き込み案。承認後、書き出しと同じ規則で書く: rekordbox
終了中のみ・バックアップ・読み戻し・不一致なら復元）。`rekordbox.propose_publish` は廃止。

- 用語: ラベル・単語・概念は英語の小文字（target / mix / predicted / improve / light / standard / bold / export to
  rekordbox …）、詳細な説明だけ日本語。プリセット・カーブ・介入度の名前も英語に（書き出し名は「acid (standard)」）。

## 3回目のレビュー（2026-10-09 夜 → 対応 2026-10-08 クラウドセッション）

- 文言: 設定の「iPhone」→「screen mirroring」、「show qr」→「show QR」。QR のモーダル見出し・停止の通知・
  接続キー無効ページの案内も同じ語に。
- プレイリストのパス（`#plPath`）: `.pl-head`（flex の行）を p に付けていたため、`.pl-head .path` の
  スタイルが当たらず、枠の際に素の文字で出ていた。専用の `.pl-path` にし、■ の後の見出しの文字頭（7px＋gap）に
  そろえた。空なら非表示。
- improve の介入度ボタンの title（LEVEL_HELP のホバー）を削除。下の `#impHelp` の 1 行と重複していた。
- ダークの予測時間の帯: 白く反転させるのをやめた。帯はダークのまま、地 #0f0e12 より一段深い #000000 にし、
  上下に明色（#f6f8f7）の 1px 罫線で「1 つだけの表示窓」として区別する。文字 #f6f8f7。トークン
  `--carbon-rule`（オリジナルでは帯と同色＝見えない）と、帯の色に依存していた primary ボタンのホバー用に
  `--primary-hover` を追加。トーストも同じ罫線。新しい色相・グラデーション・影は無し。
- **時系列の取り違えを修正**: Set Agent が触れるのはプレイ前の準備の「曲順」だけ。曲を繋ぐ（ミックスする）のは
  本番の DJ。介入度の説明・ツール説明・SYSTEM_PROMPT・はじめに.md から、Set Agent の動作としての「つなぎ／繋ぐ」を
  外し、「隣り合う曲の相性（キー・BPM）」「曲順」「並び」に。表示名 rough transitions → **clashes**
  （隣り合う曲の相性が悪い並びの数。内部のキーは `rough` のまま）。SYSTEM_PROMPT に時系列の段落を追加。
  - light: 曲は変えず、キーや BPM の相性が悪い並びだけ近くの曲と入れ替えます
  - standard: light に加えて、目標の尺に合うように曲を足し引きします
  - bold: 展開と隣り合う曲の相性に合わせて、曲順を組み直します
  - DJ 自身の過去のミックス（履歴の「この曲の後に何をかけたか」）や、尺の予測で前提にする曲間の重なりは
    DJ の行為なので「繋いだ」「繋ぎ」のままでよい。
