# Set Agent — rekordbox の横で、セットの尺と流れを見る（プロト版）

rekordbox で選んでいるプレイリストが、**全体で何分になるか**と**どこで隣り合う曲の相性（キー・BPM）が悪いか**を、
rekordbox の横に出します。使うのはプレイ前の準備のときです。曲を繋ぐ（ミックスする）のは本番のあなたで、
Set Agent が見るのは曲順だけです。選曲はあなたのものです。Set Agent はプレイリストを直しません。
頼んだときだけ、**改善版**を別のプレイリストとして rekordbox に書き出します。

---

## 1. 動かす

`SetAgent.exe`（Mac は `SetAgent.app`）を開くだけです。インストールは要りません。
Mac は `SetAgent-macOS.zip` を展開し、`SetAgent.app` を「アプリケーション」フォルダに入れてから開いてください
（Apple シリコンの Mac 専用）。
**Mac の初回は「開けません」と出ます**（Apple の公証を受けていないため）。システム設定 → プライバシーとセキュリティ の
下にある「このまま開く」を押してください。2 回目からは普通に開けます。
パネルは rekordbox のウィンドウに付いて動きます。

**Mac では初回に「アクセシビリティ」の許可が要ります**（rekordbox でどのプレイリストを選んでいるかを読むため）。
設定 →「rekordbox」の **許可する** を押し、システム設定で Set Agent をオンにしてください。
Windows は許可なしで動きます。

うまく動かないときは `SetAgent.exe --doctor` の結果を送ってください。

---

## 2. 先にやっておくこと

展開（ピーク）の分析は rekordbox の**フレーズ解析**を使います。
rekordbox の **環境設定 > 解析** で「フレーズ」をオンにして、曲を再解析してください。
クラウド保存やストリーミングの曲は rekordbox が解析しないため「解析なし」になります。

---

## 3. 画面

**rekordbox でプレイリストを選ぶと、Set Agent もそのプレイリストに切り替わります。**

| 場所 | 中身 |
|---|---|
| 見出し | rekordbox で選んでいるプレイリスト。■ 塗り = 追従中、□ 白抜き = 追従していない（名前にマウスを乗せると理由: コレクションや検索・インテリジェントプレイリストを表示中、rekordbox が解析中で応答しない、許可がない など）。許可がないときは settings に印が付き、ここでプレイリストを選べます |
| target / mix / curve / bpm | 目標の尺、1 曲をどこまでかける前提か、目指す展開、かける BPM |
| 予測時間 | その前提でかけたときの合計。超過は赤、不足は黄 |
| peak / clashes / phrase data | 盛り上がりの位置、キーや BPM が離れた曲どうしが隣り合っている数、解析のある曲の数 |
| 改善版 | 下の 4 章 |

「詳細」では曲ごとの尺と展開を時間軸で見られます。曲を右クリックすると
**マイルストーン**（要の曲）と**固定**（改善版でも動かさない）を付けられます。

**⇥** で細い帯に畳むと、予測時間・超過/不足・目標・曲数・BPM・peak・clashes が残ります。**⇤** で戻ります。

---

## 4. 改善版を作って rekordbox に書き出す

1. 介入度を選ぶ
   - **light**: 曲は変えず、キーや BPM の相性が悪い並びだけ近くの曲と入れ替える
   - **standard**: さらに、目標の尺に合わせて曲を足し引きする（足す曲はあなたのライブラリから）
   - **bold**: 展開と隣り合う曲の相性に合わせて、曲順を組み直す
2. **作る** → 予測時間と、足す・外す・動かす曲の一覧が出ます
3. **rekordbox に書き出す** → rekordbox の **「Set Agent」フォルダ**に新しいプレイリストとして入ります
   （例: 「acid (標準)」）。元のプレイリストはそのままです

- 書き出すのは rekordbox を閉じている間だけです。開いているときは「閉じたら書き出す」か「終了して書き出す」（書き出して再起動）を選べます
- 書き出す前に毎回バックアップを取ります。設定 →「書き出しのバックアップ」から戻せます
- 入るのは曲順だけです。再生範囲やテンポは rekordbox には入りません

---

## 5. エージェント（チャット）

使いたい人向けの奥の階層です。右上の **エージェント** から開きます。モデルはその欄で選べます（初期値 Opus 5.5）。

- 「私の好みは？」— 演奏履歴・インポート・レーティングから傾向を出します
- 「夜っぽいプレイリストはどれ？」— コンセプトに合うプレイリストを根拠付きで挙げます
- 「このプレイリストを整えて」— 改善版を作ります（書き出すかはあなたが決めます）
- 「この曲の後に何をかけてきた？」— 過去のセットから答えます
- 「この 3 曲のコメントに "opener" を付けて」— タグ（コメント・レーティング・カラー）の書き込み案を出します。
  書き込むのはあなたが確認してからで、書き出しと同じくバックアップを取ります

候補はあなたのライブラリにある曲だけです。Claude に接続できない PC でも、簡易モードで答えます。

---

## 6. 設定

表示（オリジナル / ダーク）、パネルの位置（横 / 内側 / 並べる / 付けない）、
書き出しのバックアップ、エージェントの声かけ、API キー（任意）、screen mirroring（iPhone で表示。同じ Wi-Fi の QR）。

---

## 7. 返してもらえると助かること

- 改善版で「**余計なお世話**」と感じた変更と、そのときの介入度
- 追従しなかった場面（rekordbox で何を選んでいたか）
- 予測時間が感覚と合わなかった場面
- `--doctor` の出力（動かなかった場合）

---

## 8. 免責

- プロト版です。書き込むのは、あなたが「書き出す」「書き込む」を押したときだけです。対象は「Set Agent」フォルダの
  プレイリストと、確認したタグだけで、その前に毎回バックアップを取ります
  （`%LOCALAPPDATA%\SetAgent\backups\`、Mac は `~/.config/SetAgent/backups/`）。
- 設定は `%LOCALAPPDATA%\SetAgent\`（Mac は `~/.config/SetAgent/`）に保存されます。消しても実害はありません。
