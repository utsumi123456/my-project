# Set Agent — セットの尺と展開を見ながら組むための道具（プロト版）

DJ セットを組んでいる最中に、**全体で何分になるか**と**どこが山でどこが谷か**を
rekordbox の横に置いて見られるようにする補助ツールです。rekordbox のライブラリをそのまま読みます。

rekordbox 本体には一切手を入れません。**master.db にも音源にも書き込みません。**
編集はすべて rekordbox 側で行ってください。Set Agent はそれを読んで数字を出すだけです。

---

## 1. 動かす

`SetAgent.exe` をダブルクリックするだけです。インストールは不要で、
Python などが入っていない PC でも動きます。

初回起動時に、この PC の rekordbox ライブラリを自動で探します。見つからない場合は
`master.db` を選ぶ画面が出ます（通常は `%APPDATA%\Pioneer\rekordbox\master.db`）。

細い縦長のパネルとして、常に手前に開きます。位置とサイズは覚えるので、
rekordbox の空いている場所に置いておいてください。

**うまく動かないときは、まず環境診断を実行してください。**

```
SetAgent.exe --doctor
```

診断結果がダイアログに出ます。**その内容をそのまま貼って報告してもらえると**原因を特定できます。

---

## 2. 先にやっておくこと（重要）

展開の分析と「再生範囲の自動決定」は、**rekordbox のフレーズ解析**を使っています。
これがないと尺の管理しか使えません。

1. rekordbox の **環境設定 > 解析** で「**フレーズ**」をオンにする
2. 曲を選んで**再解析**する（解析済みの曲も、フレーズだけは入っていないことがあります）
3. Set Agent はライブラリの変化を自動で読み直します

**クラウド保存（rekordbox Cloud Library Sync）やストリーミングの曲は、rekordbox が
フレーズ解析を行いません。** これは Set Agent 側では対応できません。
そうした曲は「解析なし」と表示され、フル尺のまま扱われます。

---

## 3. 画面の見かた

上のバーの「**セット**｜**詳細**」で 2 つの画面を切り替えます。

### セット（ふだん見る画面）

| 場所 | 意味 |
|---|---|
| 大きな数字 | **セット全体の予測時間**。目標に対して超過・不足・目標内のいずれかを横に表示 |
| バー | 予測時間と目標の関係 |
| カード | 今の状態に応じた次の一手。押すとエージェントにその指示が送られます |
| 条件 | Playlist / Target（目標尺）/ Mix（再生範囲のプリセット）/ Curve（目標カーブ） |
| 曲リスト | アートワーク・曲名・尺・累積時刻。**目標を越えた行は累積が赤**。◆ はマイルストーン |
| 最下行 | いつ時点の rekordbox ライブラリを見ているか |

### 詳細（展開を見る画面）

| 場所 | 意味 |
|---|---|
| **TRACKS** | 曲のブロック。幅＝再生時間。色付き＝フレーズ解析あり、斜線＝解析なし |
| **ENERGY** | 実測の展開（フレーズ解析から）と、あなたが選んだ目標カーブ |
| **SECTIONS** | マイルストーンで区切った区間の予算。何曲・何分・過不足・あと何曲入るか |
| **提案後**（点線） | エージェントの提案を適用したらこうなる、というゴースト |
| 削り代 | テンポや範囲の調整で稼げる時間と、超過に対してどこまで届くか |
| 選択中 | 選んだ曲のプリセット・テンポ・マイルストーン・ロック |

---

## 4. rekordbox で編集すると自動で追従します

rekordbox でプレイリストに曲を足す・外す・並べ替えると、数秒以内に Set Agent の数字と
曲リストが更新されます。rekordbox を開いたままで構いません。

Set Agent 側で試しに動かしている途中（ブロックのドラッグや提案の検討中）は、
上書きせずに「反映する」ボタンが点灯します。押すと rekordbox の最新状態を読み直します。

---

## 5. 詳細画面での操作

- **ブロックをドラッグ** → 並べ替えの試行
- **ブロックの端をドラッグ** → 再生範囲を詰める試行
- **Curve** でテンプレートを選ぶ → 目標カーブが出ます。**点をドラッグ**して意図に合わせられます
  （ダブルクリックで点を追加、右クリックで削除）
- **選択中** の欄でプリセット・テンポ・マイルストーン（目標時刻付き）・ロックを設定
- **元に戻す／やり直す** → エージェントの提案も同じ履歴に乗ります

ここでの操作は Set Agent の中だけの試行です。rekordbox のプレイリストは変わりません。
気に入った形になったら、rekordbox 側で同じ編集を行ってください。

---

## 6. エージェント（上のバーの「エージェント」）

話しかけると、分析の値をそのまま使って答えます。**数字を推測させていません。**

```
今のセット何分？
バランスどう？
区間の余白は？
60:00 に収めて
30 分あたりが平坦だから何か足したい
```

- 変更は必ず**提案**として出ます。**勝手に適用されません。** 操作ごとにチェックを外せます
- 「収めて」では、まず再生範囲を詰め、足りない分は**外す候補**を理由付きで出します
  （展開の山谷を作っている曲、ロックした曲、マイルストーンは候補に入りません）
- 候補曲は**あなたのライブラリにある曲だけ**です。曲名を作ることはありません
- **介入度 `off`** にすると、提案も通知も出ません。分析とタイムラインはそのまま使えます
- LLM は未接続でもすべて動きます（ルールベースで回答）。使う場合は **設定** から API キーを保存します

---

## 7. 返してもらえると助かること

n=1 で作られた道具です。**あなたが使って引っかかったところが、いちばんの情報です。**

- 実際に 1 セット組んでみて、**どこで手が止まったか**
- 出た数字が**感覚と合わなかった**場面（特に one_drop の切り出し位置）
- エージェントの提案で「**余計なお世話**」と感じたもの
- rekordbox で編集したのに**追従しなかった**場面（そのときの操作内容）
- `--doctor` の出力（動かなかった場合）

---

## 8. 免責

- プロト版です。あなたのライブラリには**読み取りしかしません**。
- 設定は `%LOCALAPPDATA%\SetAgent\` に保存されます。削除しても実害はありません。
