# Set Agent — セットの尺と展開を設計する道具（プロト版）

DJ セットを組むときに、**全体で何分になるか**と**どこが山でどこが谷か**を、
組んでいる最中に見えるようにする。rekordbox のライブラリをそのまま読む。

rekordbox 本体には一切手を入れない。**あなたの master.db にも音源にも書き込まない。**

---

## 1. 動かす

`SetAgentTimeline.exe` をダブルクリックするだけ。インストールは要らない。
Python も何も入っていない PC で動く。

初回起動で、この PC の rekordbox ライブラリを自動で探す。
見つからなければ `master.db` を選ぶ画面が出る（通常は
`%APPDATA%\Pioneer\rekordbox\master.db`）。

**うまく動かないときは、まずこれ。**

```
SetAgentTimeline.exe --doctor
```

環境診断の結果がダイアログに出る。**その内容をそのまま貼って報告してほしい。**
「動きません」だけだと何も分からない。

---

## 2. 先にやっておくこと（重要）

展開の分析と「再生範囲の自動決定」は、**rekordbox のフレーズ解析**を使っている。
これが無いと、尺の管理しか使えない。

1. rekordbox の **環境設定 > 解析** で「**フレーズ**」をオンにする
2. 曲を選んで**再解析**する（既に解析済みの曲も、フレーズだけは入っていない）
3. Set Agent の **Rescan** を押す

**クラウド保存（rekordbox Cloud Library Sync）やストリーミングの曲は、rekordbox が
フレーズ解析をしない。** これは Set Agent 側ではどうにもできない。
そういう曲はグレーのブロックで表示され、フル尺のまま扱われる。

---

## 3. 画面の見かた

| 場所 | 意味 |
|---|---|
| **TRACKS** | 曲のブロック。幅＝再生時間。**緑**＝フレーズ解析あり、**グレー**＝解析なし |
| **提案後**（黄色の点線） | エージェントの提案を適用したらこうなる、というゴースト |
| **SECTIONS** | マイルストーンで区切った区間の予算。何曲・何分・過不足・あと何曲入るか |
| **ENERGY** | 青＝実測の展開（フレーズ解析から）、ピンクの点線＝あなたが引いた目標カーブ |
| 右上の数字 | 総尺 / 目標尺 / 過不足 |

## 4. 操作

- **ブロックをドラッグ** → 並べ替え
- **ブロックの端をドラッグ** → 再生範囲を詰める
- **M キー**（または右クリック） → マイルストーンにする。目標時刻を入れると、ズレが出る
- **Curve** でテンプレートを選ぶ → 目標カーブが出る。**点をドラッグ**して自分の意図に合わせる
  （ダブルクリックで点を追加、右クリックで削除）
- **Ctrl+Z / Ctrl+Y** → 元に戻す・やり直す。**エージェントの提案も同じ履歴に乗る**
- **骨組みのみ** → マイルストーンだけ表示して構成を見る

## 5. エージェント（右のタブ）

話しかけると、分析の値をそのまま使って答える。**数字を推測させていない。**

```
今のセット何分？
バランスどう？
区間の余白は？
60:00に収めて
30分あたりが平坦だから何か足したい
```

- 変更は必ず**提案**として出る。**勝手に適用されない。**操作ごとにチェックを外せる
- 候補曲は**あなたのライブラリの実在曲だけ**。曲名を作ることはない
- ロックした曲に触れる提案は、表示される前に弾かれる
- **介入度 `off`** にすれば、提案も通知も一切出ない。分析とタイムラインはそのまま使える
- LLM は未接続でも全部動く（ルールベースで答える）

## 6. rekordbox に戻す

**XMLへ書き出し** を押すと、まず「何が反映されて何が反映されないか」が出る。
読んでから書き出せ。

rekordbox 側の手順（**ここを間違えると表示されない**）:

1. 環境設定 > 詳細 > データベース > rekordbox xml > **Imported Library** で書き出したファイルを指定
2. **rekordbox を再起動する** — 起動時にしか読まない
3. ブラウザ左のアイコンレールで **「rekordbox xml を表示」をオンにする**

> 取り込んだ曲をデッキに載せると「コレクションに反映するか」と聞かれる。
> **Yes を押すとあなたの本体のライブラリが書き換わる。** 意図しないなら No。

---

## 7. 何が返ってくると助かるか

これは n=1 で作られた道具だ。**あなたが使って壊れたところが、一番の情報になる。**

- 実際に1セット組んでみて、**どこで手が止まったか**
- 出た数字が**感覚と合わなかった**場面（特に one_drop の切り出し位置）
- エージェントの提案で「**余計なお世話**」だと思ったもの
- `--doctor` の出力（動かなかった場合）

## 8. 免責

- プロト版。あなたのライブラリには**読み取りしかしない**が、書き出した XML の取り込みは
  rekordbox 側の操作なので、そこは自分の判断で
- 設定は `%LOCALAPPDATA%\SetAgent\` に保存される。消しても実害はない
