# 04. デザイン・レイアウト方針（Sc0pe v2 分析ベース）

添付の `Sc0pe_2.0.0.amxd` を解析して抽出した設計パターンと、本デバイスへの適用方針。

## 1. Sc0pe v2 から抽出した設計思想

| パターン | Sc0pe での実装 | 本デバイスへの適用 |
|---|---|---|
| **jsui 一枚描画** | UI 全体を `jsui`（`Sc0pe_UI_2.0.0.js`、mgraphics）1枚で描画。ネイティブ UI オブジェクトは不使用 | 同方式。テーマ・アニメーション・ホバー UI を自由に制御でき、Claude によるコード開発と相性が最良 |
| **メッセージ駆動** | 全解析値を `prepend loud_m` 等の名前付きメッセージで jsui に集約 | `bpm 124.0 0.92` / `key 8 minor 0.87` / `chroma <12値>` 等を定義 |
| **Live テーマ追従** | `themecolor.live_lcd_bg` / `live_lcd_control_fg` を panel / comment の色式に使用 | 背景 panel + アクセントに themecolor 式を採用し、Live のスキンに自動追従 |
| **コンパクト幅** | devicewidth ≈ 131px、openinpresentation=1 | 同等（約130px）。情報密度はホバーで拡張（カーソルで詳細表示） |
| **低優先処理** | `qmetro` / `deferlow` / `speedlim` で UI 更新をオーディオと分離 | 解析結果は speedlim 500ms、UI 再描画は qmetro |
| **ホバーで文脈情報** | スペクトラムにカーソルで帯域解説（SUB-BASS 等）を表示 | クロマ表示にホバーで音名・Camelot 隣接キー（エナジーミックス候補）を表示 |
| **ダブルクリックでリセット** | Loudness 履歴リセット | 検出履歴リセットに踏襲 |
| **不可視 pattr パラメータ** | `live.numbox`（appearance 4, invisible）で表示モードを保存 | Notation / Smoothing 等の設定を同方式で永続化 |

## 2. カラーランゲージ

Sc0pe: シアン=L / アンバー=R / 白=重なり。本デバイスでは:
- **シアン** … BPM 系（リズム）
- **アンバー** … Key 系（ハーモニー）
- **グリーン/レッド** … 信頼度（高/低）。Sc0pe の位相相関表示（正=緑・負=赤）を踏襲
- 未確定値は同色の低アルファ（candidate 表示）

## 3. レイアウト案（幅130px・presentation）

```
┌──────────────────────┐
│ TuneScope        ⚙   │  タイトル行（設定はホバーメニュー）
├──────────────────────┤
│      124.0           │  BPM 大表示（シアン）
│  conf ▮▮▮▮▯  Δ+2.3   │  信頼度バー + Liveテンポ差分（クリックで反映）
├──────────────────────┤
│    8A  ·  A min      │  Key 大表示（アンバー、Camelot + 音名）
│  conf ▮▮▮▯▯          │  信頼度バー
│  ◔ クロマホイール     │  12音の強度リング（ホバーで隣接キー）
├──────────────────────┤
│ FREEZE      [hist]   │  フリーズ / 検出履歴ミニログ
└──────────────────────┘
```

- フォント: `Ableton Sans Medium`（Sc0pe と同一、Live 標準フォントで統一感）
- 数値は等幅描画（mgraphics で桁位置固定）でチラつき防止

## 4. UX 原則
1. **挿すだけで動く** — 設定不要。ロード即解析開始（loadbang / live.thisdevice 初期化）
2. **確定するまで断言しない** — 低信頼値は薄く表示。誤った Key を堂々と出すのが既存ツール最大の不満点
3. **DJ 文脈の情報を足す** — Camelot 隣接（+1/-1/relative）をホバーで提示し「次に混ぜられるキー」まで示す
4. **クリック操作は最小** — テンポ反映（1クリック）、フリーズ、リセット（ダブルクリック）の3つのみ
